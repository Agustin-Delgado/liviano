# Shortcuts

You can change all shortcuts in Settings (Ctrl+,).

| Action | Shortcut |
|---|---|
| Field | Ctrl+L (and F6, Alt+D) |
| Switch to tab by name | Ctrl+K |
| New tab / close tab / reopen closed tab | Ctrl+T / Ctrl+W / Ctrl+Shift+T |
| New private tab | Ctrl+Shift+N |
| Back / forward | Alt+Left / Alt+Right |
| Previous tab / next tab | Ctrl+Shift+Tab / Ctrl+Tab (and Ctrl+PgUp / Ctrl+PgDn) |
| Go to tab 1 to 8 / go to last tab | Ctrl+1 … Ctrl+8 / Ctrl+9 |
| Tab strip on top / on the side | Ctrl+Shift+S |
| Hide tabs / show tabs | Ctrl+S |
| Find in page | Ctrl+F |
| Duplicate tab | Ctrl+D |
| Copy address / paste and go | Ctrl+Shift+C / Ctrl+Shift+V |
| Reload / hard reload | F5 or Ctrl+R / Ctrl+F5 |
| Bookmark page | Ctrl+Shift+B |
| Bookmarks / history / downloads | Ctrl+Shift+O / Ctrl+Y / Ctrl+Shift+J |
| Reader mode | Ctrl+Shift+R |
| Floating video | Ctrl+Shift+P |
| Hide element / show hidden elements | Ctrl+Shift+H / Ctrl+Shift+U |
| Split view / close split view | Ctrl+Alt+N / Ctrl+Alt+Shift+N |
| Add tab to new group | Ctrl+Shift+G |
| Focus left page / focus right page | Alt+Shift+Left / Alt+Shift+Right |
| Passwords | Ctrl+Alt+L |
| Full screen | F11 |
| Zoom in / zoom out / reset zoom to 100% | Ctrl+= or Ctrl+wheel up / Ctrl+- or Ctrl+wheel down / Ctrl+0 |
| Settings | Ctrl+, |

To put the tab strip on top or on the side, use Settings → Tabs → Position.
You can also hide the tabs there. The right-click menu of a tab, or of the
empty area of the tab strip, has the same commands: "Tabs on the side" and
"Tabs on top".

Another program can hold a shortcut for the full system. For example,
PowerToys often holds Ctrl+Shift+S. In that case, the shortcut list in
Settings marks the shortcut "Used by another program". Nea does not receive
that shortcut. Assign a different shortcut.

The engine does the zoom in and the zoom out. You cannot change these two
shortcuts. Nea does the reset (Ctrl+0), and you can change its shortcut.

These commands are in the tab menu (right-click) and have no default
shortcut: "Pin tab", "Keep site awake", "Block ads on this site" and "Allow
pop-ups on this site". You can assign a shortcut to them in Settings.
