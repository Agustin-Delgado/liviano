# Código de conducta

Nea es un proyecto abierto y queremos que participar sea una buena
experiencia para cualquiera, sin importar su origen, identidad o nivel de
experiencia.

## Lo que esperamos

- Tratar a las demás personas con respeto, también cuando no hay acuerdo.
- Criticar ideas y código, nunca a quien los escribió.
- Dar por hecho la buena fe y pedir aclaraciones antes de suponer.
- Aceptar con calma que una propuesta no entre.

## Lo que no se acepta

- Insultos, burlas, acoso o ataques personales.
- Comentarios discriminatorios de cualquier tipo.
- Publicar datos privados de otra persona sin su permiso.
- Insistir en un tema después de que se pidió dejarlo.

## Qué pasa si no se cumple

Quien mantiene el proyecto puede editar o borrar comentarios, cerrar issues y
pull requests, y bloquear a quien no respete estas pautas. Para avisar de un
problema en privado, usá el reporte privado de GitHub
(*Security* → *Report a vulnerability*) y aclará que es sobre conducta.

Este código está inspirado en el
[Contributor Covenant](https://www.contributor-covenant.org/).
